# 那只放弃挣扎的狗 · 交互网页版

纯静态站：`index.html` + `css/style.css` + `js/*.js` + `media/`，**不需要 npm、不需要构建**。

## 怎么跑

**双击 `start.bat`**（推荐）。它会用本机 Python 3 启动一个支持 Range 的本地服务，
自动打开浏览器，地址形如 `http://127.0.0.1:8123/`。关掉黑窗口即停止。

手动等价命令：

```
cd site
py -3 serve.py 8123        # 或 python serve.py 8123
```

为什么不用 `python -m http.server`：它不支持 Range 请求，浏览器拿不到 206，
`<video>` 的进度条就拖不动。`serve.py` 补了这个。

也可以直接双击 `index.html`（`file://`）：页面、对话、字幕都能用，
但视频拖动定位可能被浏览器限制——要拖进度条就用上面的服务方式。

## 播放器（本次改动）

成片 `media/那只放弃挣扎的狗_伴学版.mp4` 是 1280×720，其中 **602–716px 已经烧死了字幕条**，
里面还画了小柴。所以网页上原来会出现三层叠加：成片字幕 + 网页字幕浮层 + 小柴，都压在画面上。

现在：

| 控件 | 作用 |
|---|---|
| **净版 / 原版** | 净版（默认）按 `16:7.5` 把画面裁到 600px 高，正好切在字幕条上边缘；切原版恢复完整 16:9 帧 |
| **字幕条** | 移到播放器**外面**，一行独立区域，由 `js/data.js` 的 106 条 cue 驱动，永远不遮画面。原版模式下自动收起，避免和成片字幕叠成两层 |
| **控制条** | 也是画面**下方**的独立一条（深色，46px），不像常见播放器那样浮在画面上，所以暂停时也不会压住最后一页文字 |
| **CC** | 字幕条开关 |
| **缩放 − 100% +** | 画面 100%–250% 缩放；放大后可以直接**拖动画面**平移；点百分比复位；`Ctrl+滚轮` 缩放 |
| **全屏** | 原生全屏，被 iframe 权限挡住时自动退化成「占满窗口」的伪全屏；双击画面也可切换 |
| 键盘 | `空格` 播放/暂停，`←/→` ±10 秒，`+/-` 缩放，`0` 复位缩放，`Esc` 退出全屏 |

`preview-desktop.png` / `preview-mobile.png` 是改好之后的效果截图（1440 宽桌面 / 390 宽手机）。

播放器状态（净版/字幕/缩放/倍速）存在 localStorage，下次打开保持。

## 其它

- 字幕与章节时间轴由 `tools/video` 生成进 `js/data.js`，**不要手改**（文件头有说明）。
- 小柴是手写 SVG（`index.html` 里 `#dog`），动作由 `css/style.css` 驱动，语音走 `js/voice.js`（`speechSynthesis`）。
- 对话三层：本地知识库 `js/kb.js`（52 条）→ 越界才转 DeepSeek（`js/llm.js`，Key 存本机）→ 危机/诊断在本地硬拦截。
  联网默认关闭，教师端「语音与联网」填 Key 后生效。
- 自测引擎：`node ../tools/test_engine.js`（22 条用例）。
