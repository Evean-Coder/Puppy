**技术结论（可复用）**
- `site/` 全部是相对路径，可直接静态托管；Render 自带 CDN 支持 Range，
  本地 `serve.py` 只是为 `file://`/简易 http server 场景补 Range。
- 部署前本地用 `python -m http.server` 验证：首页/6 个 js/章节数据/幻灯片/中文名 mp4 全 200，
  说明中文文件名在静态托管下不会被坑（GitHub 上传后字节数 14,624,488 与本地一致）。
- 本机 `raw.githubusercontent.com` 被阻断（返回 000），验证远端文件要走 `api.github.com/contents`；
  `api.github.com` 正常 200。这不影响 Render 拉代码。
